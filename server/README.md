# Сервер канбан-доски

REST API по [контракту](../docs/api-contract.md). FastAPI + SQLite, без внешних сервисов.

## Запуск

```bash
./run.sh
```

Скрипт ставит зависимости и поднимает сервер на `http://localhost:8000`.
API живёт под `/api/v1`, интерактивная документация — `http://localhost:8000/docs`.

Вручную, если окружение уже готово:

```bash
pip install -r requirements.txt
python3 -m uvicorn main:app --host 0.0.0.0 --port 8000
```

## Тесты

```bash
cd server && python3 -m pytest
```

29 тестов: CRUD, фильтрация, комментарии, граничные случаи, персистентность.
Каждый тест получает свою временную БД, рабочие данные не трогаются.

## Хранилище

SQLite-файл `server/kanban.db`, создаётся при первом старте. Путь переопределяется
переменной `KANBAN_DB`:

```bash
KANBAN_DB=:memory:      ./run.sh   # эфемерная база
KANBAN_DB=/tmp/qa.db    ./run.sh   # отдельная база для прогонов QA
```

**Чистый старт:** удалить файл БД — схема и seed создадутся заново.

Seed — 6 карточек в четырёх статусах, заливаются **только в пустую базу**,
поэтому рестарт не плодит дубли.

| Файл | Зачем |

## Трактовки контракта

Места, где контракт допускал разночтения, — решены так:

- **Формат ошибок.** Контракт требует `422 {"detail": "..."}` строкой. FastAPI по
  умолчанию кладёт в `detail` массив объектов, поэтому стоит обработчик, приводящий
  его к строке. Ответ соответствует букве контракта.
- **Комментарий на выходе** — `{id, card_id, text, created_at}`; сортировка по
  `created_at`, при совпадении метки — по `id` (SQLite вставляет быстрее, чем тикает секунда).
- **`PATCH` с пустым телом** — `200` и карточка без изменений, `updated_at` не двигается.
- **`updated_at`** обновляется только при фактическом изменении значений.
- **`title`** — обрезаются пробелы по краям, затем проверка: пустой → `422`, >200
  символов → `422`. Лимит считается в символах.
- **`?status=` с пустым значением** — фильтр не применяется (пустой `select` на фронте
  не должен ловить ошибку). С непустым мусорным значением → `422`.
- **Комментарии к несуществующей карточке** (`GET`/`POST`) → `404`.
- **Удаление карточки** каскадно удаляет её комментарии.
- **CORS** открыт для всех origin: фронтенд работает с другого порта. Для спринта 1
  без авторизации это безопасно; при появлении логина список нужно сузить.
