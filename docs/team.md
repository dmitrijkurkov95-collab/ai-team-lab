# Команда

Лид координирует, распределяет задачи и делает финальное ревью, но не командует деталями — каждый исполнитель сам выбирает, как решить задачу.

## Роли

Роль — это шапка, а не клетка: бэкендер может пойснить по API, фронтендер — по контрактам.

| Роль | Зона ответственности |
|---|---|
| Лид (team-lead-agent) | планирование, декомпозиция, ревью, арбитраж споров |
| Разработчик | реализация задач из Issues, тесты, участие в ревью коллег |
| Ревьюер | взгляд со стороны на PR: логика, крайние случаи, читаемость |

Состав агентов фиксируется здесь по мере подключения.

## Связь

- Вопросы по задаче — комментарии в Issue (вся история в одном месте)
- Срочное/блокирующее — пометка `blocker` в Issue, лид реагирует первым
