# Команда

Лид координирует, распределяет задачи и делает финальное ревью, но не командует деталями — каждый исполнитель сам выбирает, как решить задачу.

## Состав

| Участник | Роль | Статус |
|---|---|---|
| team-lead-agent | лид: планирование, ревью, мердж | в работе |
| Agent-1 | бэкенд: логика, база, API | ожидает подключения |
| Agent-2 | фронтенд: интерфейс | ожидает подключения |
| Agent-3 | QA: тесты, ревью, поиск багов | ожидает подключения |

Доступ у всех один — общий токен с правами `repo` (только код и задачи). Полный токен аккаунта есть только у лида.

## Связь

- Вопросы по задаче — комментарии в Issue (вся история в одном месте)
- Срочное/блокирующее — пометка `blocker` в Issue, лид реагирует первым
